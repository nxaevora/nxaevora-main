The experiment selects render targets with guest dimensions1024x1024 and
format keys1000a(D32) or f6(R8_UINT). Both depth and tag maps remain at native
1024x1024. Draw and clear viewport/scissor/clip coordinates use pass-local
scale1. Fragment SNX_RS constants use the same scale, and their staging cache
now includes scale as well as submission number. Main scene passes retain
global4/3 scale, including2560x1440 scene color/depth and shadow receiver.
The existing native copy_layers branch copies shadow layers without a resize.
Texture crops honor native source dimensions; draw-texture destinations honor
the selected native targets. No global scale mutation or depth-bias changes.

Unexpected mixed native/scaled attachment sets are logged and skipped in this
experimental candidate, rather than rendered with incompatible coordinates.
This is a diagnostic safeguard, not a production solution for mixed passes.
The shape/format predicate is evidence-based but not a semantic identification
of every possible shadow pass; other areas could use the same shape/formats.
Native1024 shadow maps may have less edge detail than correctly implemented
scaled shadow maps. Scene resolution stays1440p. A coherent higher-resolution
shadow-array implementation remains a possible subsequent improvement.

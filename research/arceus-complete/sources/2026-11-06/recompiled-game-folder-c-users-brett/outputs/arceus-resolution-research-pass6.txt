ARCEUS 1.1.1 RESOLUTION MODE RESEARCH — PASS 6
2026-11-06. Local static analysis and isolated original-instruction execution.
Addresses are hexadecimal main-relative; original main load base is0x8005000.

Result
The engine has separate automatic and explicit controls for3D buffer scale.
The automatic governor is not the only possible reason for a smaller viewport.
An event transition can request half scale, and a script-bound callback can set
custom width/height scales. A separate signed override takes precedence over
the stored mode. None of this establishes the actual scene resolution in the
latest user run: resolution tracing and both rendering experiments were off.
The user reported good visual quality, below1440p, without the previous distortion.

Temporary event mode, inside1DF4178
At1DF5074..5098, a field/event state branch reads the resolution owner's
requested mode. If it is not already7, it saves that mode to event object+258,
then stores requested mode7 through1DF5B14 and callsCC3888 at1DF5B18.
At1DF5B04..18, a later branch compares saved+258 against current requested mode
and restores/applies it when different.

This is a requested-mode save/restore, not a snapshot of effective resolution:
- owner+28 override can supersede mode7, so half scale is not inevitable.
- The path does not save/restore override or custom float values.
- Already-mode7 bypasses the save in the observed branch.
- These branches do not prove every abort/cancel/error reaches the restoration.
No claim of a stuck half-resolution bug is justified by this static path alone.

Relationship to the existing optional governor bypass
CC35A4's update selects requested/override mode using the same signed comparison,
then only accepts effective modes1..3 into its update branch. The existing
SNX_ARCEUS_FIXED_RESOLUTION experiment changes its range check to take the
ordinary early return. It leavesCC3888 and explicit scene modes intact.
That experiment therefore does not itself force all scenes to full scale or
prove1440p output. It was disabled in the completed controller test.

The prior optional screen-fetch shader candidate is also still disabled. It
addresses host render-scale coordinate quantization, which is separate from
these game-side scale choices. No visual success at1440p is claimed for it.

Arceus 1.1.1 timing investigation - 2026-11-06

All addresses are offsets relative to main, not absolute process addresses.
Local static investigation plus review of the existing test log. No runtime
source, executable, game content, or save was changed during this pass.

RESULT

The original 40 sites are not 40 independent animation clocks. They include
live timers, movement calculations, unit conversions, and initialization defaults.
The expanded scan found 47 positive and 11 negative float 1/30 constructions:
58 sites altogether. It also found nine +/-1/60 or +1/120 constructions and
the existing 33,333,334-nanosecond clock default.

Most actionable new finding: an unpatched copy of the blink countdown inside
main+1AAF0B4. It directly decrements the same +68C counter as the two previously
patched base functions. NPC/common character animation tables contain this
function. It bypasses the patched base functions. This is a strong explanation
for the failed blink test, pending a live callback measurement.

Controller camera acceleration and angular integration are separate. The last
candidate changes the response ramp at 193C04C. Sustained rotation is calculated
elsewhere, including 193D16C, where configuration/input values are multiplied
and added to the angle on each update. Changing only acceleration cannot correct
per-update turning distance.

AI navigation and rigid-body physics each have a conditional override that
replaces supplied elapsed time with 1/30. Their constructors initialize the
examined mode flags to the fixed-step setting. Live mode and call cadence remain
to be measured; neither is yet proven to be causing the thrown-ball problem.

Dialogue skipping remains unresolved. The latest field-message probe logged its
installation but no callbacks. It has not established the active conversation
path. Correct text appearance and correct minimum advance delay are separate.

EVIDENCE LABELS

Confirmed operation/subsystem does not mean confirmed once-per-render cadence.
A static fixed constant is not by itself proof of a high-FPS bug.
Likely feature interpretations and unresolved details are explicitly marked.
Several nominal frame/second conversions should retain their original units.

SCOPE / LIMITS

Indexed 161,057 main-text function ranges using local recompiler metadata.
Inspected ARM64 instructions, direct callers, vtables, names, reflection metadata
and the local test log. Expanded searches include W/X constant construction,
short nonadjacent builds, literal/ADRP-load candidates, signed rates and simple
object counters. Generic counter patterns are candidates, not thousands of bugs:
many represent reference counts, collection lengths or state transitions.

This is not proof every frame-dependent path has been found. Asset-authored
durations, arbitrary smoothing coefficients, inlining, indirect calls, scripts,
optimized integer division and scheduling can hide more dependencies.
Unresolved labels above are intentional. No new run or blanket replacement.

2026-11-06, user preference: every launch must support the controller.

Arceus-Controller-Test.exe in this outputs folder. It starts the game directly

exposed no targetable window even though the game started. Always inspect the
returned desktop window inventory and the new local game-err.txt before retrying.
Do not launch twice merely because the helper has no window.
